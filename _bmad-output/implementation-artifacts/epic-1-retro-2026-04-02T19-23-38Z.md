## Part 1 — What we shipped (grounded in story records)

**Story 1.1 — Backend scaffold**

- Express + Prisma v6, full schema, `pg_trgm` + GIN on `organisation.name`, `$use` middleware for `last_updated`, meta + health endpoints, Docker (`db` + `backend`), seed for reference data, `COUNTRIES` as named CommonJS export from `seed.js`.
- **Emergent decisions:** Jest + Supertest and Express v5 landed in code; captured as ADR-003 and ADR-004.
- **Friction called out in dev notes:** Jest mock factory naming (`mock*` prefix), migration SQL ordering (extension/index vs tables), Docker unavailable in some dev sandboxes → migrations authored carefully offline.

**Story 1.2 — Frontend scaffold**

- Vite + React, Tailwind v3, React Router v6, TanStack Query v5, `SelectionProvider` / `useSelection`, placeholder routes, shadcn-style `Button`, `countries.js` mirroring backend, frontend Docker service with `--host 0.0.0.0`.

**Story 1.3 — Documentation**

- README: clone → env files → `docker compose up`, ports, smoke checks aligned with `{ data, error, meta }`, threat model, pointer to Story 5.2 extensions.
- `docs/decisions.md`: compliance mapping + ADR-005–008 (Tailwind v3, shadcn copy-paste, `react-router-dom@6`, country dual maintenance).
- `.gitignore`: `.env.*` / `!.env.example`, Prisma-under-`node_modules` commentary.
- **Follow-up:** ESLint issues in `button.jsx` and `SelectionContext.jsx` deferred to `deferred-work.md` (not blocking foundation).
