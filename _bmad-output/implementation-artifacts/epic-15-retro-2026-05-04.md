## 2. Story-Level Synthesis

### 2.1 What Went Well

- **Layered defence:** Hard guard at DB (`15-1`), narrow API for fuzzy hints (`15-2`), non-blocking staff UX with explicit acknowledgement (`15-3`) — matches architecture intent (ADR-026, UX-DR48/49).
- **Operational rigour:** Pre-flight `GROUP BY` diagnostic recorded in Dev Agent Record; README runbook touched for deployment awareness (`15-1`).
- **Error contract:** `P2002` mapped to a specific 409 envelope for the composite key; generic path for other unique violations (`15-1`).
- **Security / correctness in raw SQL:** Parameterised `$queryRaw`, `escapeIlikePattern` for `ILIKE` after review (`15-2`).
- **Route safety:** Static `check-similar` registered before `/:id`; UUID guard pattern already in use (`15-2`).
- **Frontend quality:** Debounced hook, blur-driven fetch (≥3 chars), `aria-live="polite"`, Vitest coverage for hook, warning, form flow, and 409 path (`15-3`).
- **Review responsiveness:** Several patches landed the same pass (ADR cross-links, `excludeId` whitespace, integration teardown by `id`, JSON parse hardening, surfacing check-similar failures in UI).

### 2.2 Challenges & Patterns (systems, not blame)

- **Host vs Docker for backend Jest:** Recurring theme from Epics 12–14 — `15-1` / `15-2` document `EACCES` on `node_modules` and green runs via `docker compose run … backend npm test`. **System fix:** one documented “healthy path” and ownership hygiene on the host.
- **Wide change-sets on a narrow epic:** Reviews called out sprint-status and unrelated areas (sort, `fieldSources`) bundled with 15.x work — increases review risk and blurs accountability. **Process:** prefer narrower commits when practical; when batching is unavoidable, call it out in PR/release notes (already noted in story reviews).
- **Integration tests conditional on `DATABASE_URL`:** `describe.skip` when unset means CI can go green without exercising DB paths. **Risk:** silent gap unless pipeline always provisions a DB for backend jobs.
- **Deferred technical nits:** `isOrganisationNameCityCountryUniqueViolation` uses substring `includes('name_city_country')` — low probability of mis-routing but called out for exact matching next touch (`15-1` / `15-2`).

### 2.3 Recurring Review / Quality Themes

- **Migrations are procedural, not only code:** Pre-flight before Migration C is part of the definition of done.
- **Minimal DTOs for narrow endpoints:** Avoid leaking `toOrganisationDto` through `check-similar`.
- **UX edge cases after review:** Lookup errors surfaced in create UX; 409 without `fields` still maps to name summary via `mergeCompositeConflictNameMessage`.
