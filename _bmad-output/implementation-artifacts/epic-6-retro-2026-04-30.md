## 2. Story-level synthesis

### 2.1 What went well

- **Three-migration discipline honoured:** Migration A stayed additive (`CREATE` only); ADR in `docs/decisions.md` captured the additive → backfill → destructive sequence (`6.1`). Prisma `--create-only` drift (e.g. unwanted `DROP INDEX` on legacy trigram indexes) was caught and stripped so A stayed clean (`6.1` Dev Agent Record).
- **Operational realism on B:** Invariant (d) (UK + Tessitura) was made **conditional** so migrate-before-seed on an empty DB does not abort — planning (`epics.md`, `architecture-v2-delta §6.2`) was updated to match implementation (`6.2` Review Findings, Decision 1).
- **Backfill structure:** Labelled transactional steps, temp translation maps, dedup for integrated collapse, `NOT EXISTS` for CRM after ticketing, and `RAISE` on invariant failure (`6.2`).
- **Seed + legacy bridge:** `links` arrays on sample orgs; strip helpers and tests for server-managed keys before Epic 7 APIs (`6.3`); dual `system-geographic-focus.js` with ADR-016.
- **Review caught a subtle ordering bug:** Legacy FK derivation from `links` when `SECONDARY` appeared before primary roles — fixed by explicit resolution order (`6.3` Review Findings).

### 2.2 Friction and risks (systems, not blame)

| Theme | Evidence | Forward note |
|--------|-----------|----------------|
| Docker / file ownership | Migration dir owned by root without bind mount (`6.1`) | Document compose workflow for migration authors |
| Prisma migrate interactive drift | Additional migration prompt after apply (`6.1`); ADR-015 `migrate deploy` in CI | CI/CD path should use non-interactive deploy |
| Engine mismatch in Alpine vs host | `db seed` in container vs host generate (`6.2`) | Align `prisma generate` target with image; prefer documented `docker compose exec backend …` |
| Jest vs Postgres | Migration B test is structural/regex only (`6.2` deferral) | Disposable Postgres in CI would raise confidence |
| Managed Postgres | `pgcrypto` extension may need platform support (`6.2` deferral) | Runbook check before production migrate |

### 2.3 Technical debt / follow-ups recorded in stories

- Optional integration test: `prisma.system.update` bumps `last_updated` (`6.3` deferral).
- Full migrate + seed smoke in CI without disposable DB still a gap (`6.3`).
- Structural Jest for Migration B — expand when CI has Postgres (`6.2`).
