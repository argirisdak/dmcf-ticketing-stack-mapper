## 2. Story-Level Synthesis

### 2.1 What Went Well

- **Three-migration discipline held:** `10-1` kept Migration C destructive-only; optional `migration-drop-legacy-c-sanity.test.js` reduced wrong-SQL risk; seed reshaped so `migrate reset` stays coherent without legacy lookups.
- **Clear sequencing:** Backend schema + seed + meta compile path (`10-1`) → explicit JSON 404 + frontend dead-code removal (`10-2`) → operator-facing README + ADR closure (`10-3`) matched dependencies and avoided dangling client calls to removed routes.
- **Review signal was specific:** Tighter sanity-test assertions, global 404 envelope vs HTML, ADR-009 v2 DTO amendment, `sprint-status.yaml` timestamp hygiene — patches were traceable to files and ACs.
- **Documentation closure:** README smoke list now matches v2 routes and behaviours; ADR-018–024 plus index update; `CLAUDE.md` aligned in `10-3` completion notes — reduces “delta doc only” onboarding friction.

### 2.2 Challenges & Patterns (systems, not blame)

- **Cross-epic / combined-branch scope:** `10-1` and `10-2` review notes acknowledge intentional combined PRs (Epic 9 + migration + tracking); improves trunk speed but **raises bisection and review-isolation cost** — process tension called out explicitly in `10-2`.
- **Operational AC vs code:** Backup-before-Migration C is runbook/README truth, not something the test suite proves — correct placement in `10-3`, but operators must still **execute** the checklist in real environments.
- **`DROP … IF EXISTS` semantics:** Review defer notes silent skips if constraint names diverge from init migration — **verification against target DB** remains part of safe rollout.
- **Residual product QA:** `10-2` defers compare-org strip edge cases (union helper readiness); not Epic 10 blockers but **feeds the ongoing manual-smoke theme** from Epic 9.

### 2.3 Recurring Review Themes

- **Envelope consistency:** Route-level 404 shape vs resource-not-found patterns — consciously matched epic text for global 404.
- **Deferrals with explicit owners:** Frontend meta cleanup deferred from `10-1` to `10-2` with zero consumer imports — good example of documented handoff.
