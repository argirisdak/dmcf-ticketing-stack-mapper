## 2. Story-Level Synthesis

### 2.1 What Went Well

- **Clear contract split:** `13-1` centralised validation in `backend/src/lib/validate-custom-attributes.js` with explicit AC7 Jest coverage; empty-row strip, `[]` → null clear, PUT omit vs preserve documented in dev notes.
- **Review closure:** Reject body with both `customAttributes` and `custom_attributes`; case-insensitive HTTP scheme with normalised stored prefix (`13-1` Review Findings).
- **UI patterns:** Stable `_key` for rows; deterministic hydration in edit mode; shared `custom-attributes-form.js` + Vitest on editor and helpers (`13-2`).
- **Heading consistency:** Review raised Capabilities section to `text-lg font-semibold` to match Custom attributes (`13-2`).
- **Independence called out:** Dev notes explicitly separate `field_sources` from `customAttributes` — reduces accidental coupling bugs (`13-1`).

### 2.2 Challenges & Patterns (systems, not blame)

- **Agent environment vs local:** Both stories note backend Jest blocked by `node_modules` / `EACCES` (e.g. `unrs-resolver` postinstall) — same class of friction as Epic 12; implementation verified where possible, full suite expected on a healthy host/Docker path.
- **Branch noise:** `13-1` review deferred “extended capabilities + fieldSources + 13.1 on dirty branch” — integration speed trades off against bisection and review focus.
- **Deferred limits:** Unbounded `customAttributes` array length left for future cap if product needs it (`13-1`).
- **Form surface area:** `13-2` deferred `SystemFormPage.jsx` split — file remains a mixed-concern hotspot for the next form touch.
- **Manual smoke:** `13-2` recommends browser pass (add two attrs → detail; edit → remove) — not evidenced as executed in the agent environment.

### 2.3 Recurring Review Themes

- **Silent strip vs 400:** Unknown keys stripped on custom attribute objects — aligns with tolerant read DTO posture (`13-1`).
- **UX vs strict validation:** Inline char counters and URL scheme check on frontend; mirror rules on API — good two-layer story.
