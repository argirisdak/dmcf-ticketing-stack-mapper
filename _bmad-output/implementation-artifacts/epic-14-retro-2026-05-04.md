## 2. Story-Level Synthesis

### 2.1 What Went Well

- **Single source of truth for API keys:** `backend/src/lib/sort-allowlists.js` drives validation; services export testable `build*ListOrderBy` helpers (`14-1`).
- **Relation sorts handled explicitly:** `organisationType` → nested `organisation_type.name` documented and tested (`14-1`).
- **Validation UX:** Invalid `sort` / `order` return structured `fields[]` on both list endpoints (`14-1`).
- **Frontend contract symmetry:** `sort-options.js` mirrors allow-lists; `normalise*SortFromUrl` rejects unknown combinations and falls back to `name` + `asc` (`14-2`).
- **URL as source of truth:** Combined `field:direction` `<select>` values; `setSearchParams` clones existing params and only touches `sort`, `order`, `page` (`14-2`).
- **Query cache correctness:** `useOrganisations` / `useSystems` include `sort` and `order` in `queryKey` (`14-2`).
- **Automated coverage:** Jest on controllers + services (`14-1`); Vitest on `SortDropdown` including `organisationType:desc` parsing (`14-2`).
- **Review hygiene:** `14-1` deferred organisation list pagination hardening as pre-existing; documented in Review Findings rather than silently ignored.

### 2.2 Challenges & Patterns (systems, not blame)

- **Host vs Docker for backend Jest:** Same theme as Epics 12–13 — `14-1` verified full suite via Docker; `14-2` notes host `EACCES` / runner issues. The team relies on **one documented healthy path** for green backend tests.
- **Allow-list drift risk:** Frontend `ORGANISATION_SORT_OPTIONS` / `SYSTEM_SORT_OPTIONS` must stay aligned with backend arrays — **process**: any change to `sort-allowlists.js` requires the same commit to touch `sort-options.js` (called out in story dev notes and ADR-028).
- **Pagination tie-breakers:** `14-1` dev notes flag non-unique sort keys and possible future `orderBy` tiebreaker — **not** a bug today; watch if users report row “jumping” between pages.
- **Manual smoke:** `14-2` recommends a browser pass on `/organisations` and `/systems` (filters + back/forward) — **not** evidenced as executed in every agent environment.

### 2.3 Recurring Review / Quality Themes

- **Compose, don’t special-case:** Sort layers cleanly on top of existing filter + search + pagination (`14-1` AC6).
- **Staff-facing copy:** Labels use “A→Z” / “newest first” instead of `asc`/`desc` (`14-2`).
