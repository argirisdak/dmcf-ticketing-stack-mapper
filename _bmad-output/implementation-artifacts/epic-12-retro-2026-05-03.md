## 2. Story-Level Synthesis

### 2.1 What Went Well

- **Single ordering constant:** `CAPABILITY_ROWS` / `system-capabilities.js` killed form–detail–compare drift (`12-3`).
- **Migration hygiene repeated:** `12-1` rewrote Prisma output to **five additive `ADD COLUMN` statements** — same playbook as Epic 11.
- **Controller coherence:** `SYSTEM_EXTENDED_CAPABILITY_FIELDS` + shared normalisation kept write and filter paths DRY (`12-2`).
- **Filter UX:** Collapsible extended capabilities with URL deep-link behaviour, active chips, and count badge (`12-4`) — sidebar stays scannable.
- **Honest catalogue:** `12-5` enforced **YES/NO ⇒ source URL**; `UNKNOWN` omits keys; Jest AC4 guard on three reference triples avoids “flat compare” false positives.
- **Review decisiveness:** AC3 documented to match existing v1 filter error shape (`Select a valid option`); planning/epics updated when implementation truth diverged.

### 2.2 Challenges & Patterns (systems, not blame)

- **Cross-epic bundling:** Multiple reviews **accept** mixed `fieldSources` + capability work on one branch — faster integration, **harder story-isolated review** (explicit decision in `12-1` / `12-2`).
- **Local environment friction:** Repeated notes: root-owned `backend/node_modules`, `EACCES`, missing `jest-circus` — **environment hygiene**, not domain risk; Docker path used to green suites (`12-2`, `12-3`, `12-5`).
- **Test shim fidelity:** `matchesWhere` in `system-http-stack.test.js` — deferred notes on AND semantics vs Prisma (`12-2`, `12-5` patch improved AND composition once).
- **Planning vs shipped UI:** `12-3` review: capability rows on compare use labelled badges (“Not recorded”) vs literal `—` in some AC text — **planning copy lag**; no revert required.
- **Deferred service semantics:** `createSystem` `?? undefined` on new columns — watch if `null` vs omit ever becomes user-visible.

### 2.3 Recurring Review Themes

- **Parametrised tests:** `it.each` for five capabilities on GET invalid, POST invalid, filters — good parity template for future flags.
- **Magic numbers removed:** `SYSTEM_COMPARE_CAPABILITY_BLOCK_START_ROW` exported instead of hard-coded `6` (`12-3`).
- **Hydration safety:** Coerce out-of-enum API strings to `UNKNOWN` in form state (`12-3`).
