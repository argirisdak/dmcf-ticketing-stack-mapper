## 2. Story-Level Synthesis

### 2.1 What Went Well

- **Deliberate mirroring of organisation compare:** `useCompareSystems` matched `useCompareOrganisations` patterns (parallel queries, `SystemNotFoundError` no-retry, `['systems', id]` cache alignment with `useSystem`). Reduced cache-shape bugs.
- **Story sequencing worked:** 9.1 shell → 9.2 `SystemCard` + shared `CompareColumnShell` → 9.3 union + entry points kept merge conflicts manageable and kept AC boundaries testable.
- **Review loops were high-signal:** Multiple patches per story (id caps, invalid dates, null column UI, union timing until queries settle, section dividers, URL encoding, `useMemo`/`useQueries` stability). Findings were specific and traceable to files.
- **Pure helpers + Vitest:** `system-compare-union-labels`, `system-compare-custom-attributes`, org system-union strip, contextual compare helpers gained unit tests — good foundation for Epic 10 refactors.
- **Closed Epic 8 product debt:** Wrong **Compare these systems →** target and missing org-compare system strip were explicitly fixed in 9.3, matching PRD journey intent.

### 2.2 Challenges

- **Layout and query-state edge cases:** Early versions risked blank columns (`SystemCard` null path), shifting row counts while queries resolved (union-before-settle), and divider misalignment across columns — all addressed, but required iteration.
- **Spec vs implementation drift:** Row label wording (**Deployment model**), section order (Provenance vs Additional attributes), and AC details needed reconciliation mid-flight (documented in story review sections).
- **Manual verification gap:** Story 9.2 left one manual checklist item unchecked in the record; Story 9.3 notes Task 6 manual smoke not run in-session. Automated coverage improved; **hands-on compare journeys** (2 / 4 / 5+ linked systems, org strip edge cases) remain the quality backstop.
- **Documentation lag:** Compare URL references in README / broader docs were explicitly out of scope for 9.1; Epic 10 owns much of the v2 doc churn — team should not assume external docs match UI until 10-3 lands.

### 2.3 Recurring Review Themes

- **TanStack Query + layout coupling:** Unstable memoisation around `useQueries` results; resolved by deriving from cheap pure helpers each render where appropriate.
- **Never-blank / error UX:** Column-level error UI, page-level error when fewer than two valid systems vs per-column errors — clarified across 9.1 → 9.2.
- **Parity with detail pages:** Custom attribute value/source treatment, `formatLastUpdated`, category badges — repeated “match `SystemDetailPage`” theme.
